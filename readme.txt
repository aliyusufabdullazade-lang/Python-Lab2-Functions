PYTHON EXERCISES
======================================================================

A collection of beginner to intermediate Python scripts covering 
functions, argument handling, data structures, and list manipulation.


FILES IN THIS REPOSITORY
----------------------------------------------------------------------

1st exc.py
- Demonstrates positional arguments and handling missing parameter errors (TypeError)[cite: 2].

2nd exc.py
- Shows default parameter values (vat_percent=18) and keyword argument syntax[cite: 3].

3nd exc.py
- Demonstrates optional string parameters and conditional formatting[cite: 4].

4th exc.py
- Combines dictionary-returning functions with interactive user input loops[cite: 5].

5th exc.py
- Demonstrates in-place list mutation versus returning a new list using copy slicing (scores[:])[cite: 6].

6th exc.py
- Explores variable-length arguments (*args for averages and **kwargs for dynamic dictionary creation)[cite: 7].

8th exc.py
- Demonstrates list processing for total price calculations with discounts and order formatting[cite: 8].


HOW TO RUN
----------------------------------------------------------------------

Run any file directly using Python from your terminal:

  python "1st exc.py"
  python "2nd exc.py"
